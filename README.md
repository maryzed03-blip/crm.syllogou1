# Κεντρικό Hub Διοικητικού Συμβουλίου

Κεντρική εφαρμογή λειτουργίας του ΔΣ με κοινή εικόνα, tasks, Γραμματεία, οικονομικά, σεμινάρια και σύνδεση με το υπάρχον Ημερολόγιο δράσεων.

## Τι περιλαμβάνει

- Κοινή Αρχική και καρτέλες των 5 ρόλων του ΔΣ.
- Επεξεργάσιμα ονόματα ΔΣ.
- Κοινές εργασίες και workflows.
- Firestore του Hub για κοινά δεδομένα.
- Ταμείο με Μέλη 20€/έτος και Φίλους 10€/έτος.
- Αυτόματη ουρά «Προς έλεγχο» όταν συμμετέχων δηλώνει ότι έκανε κατάθεση.
- Γραμματεία με επαφές, newsletter/history και HTML Email Builder.
- Email templates με την οπτική ταυτότητα Σ.Ε.ΨΥ.G.
- Σύνδεση με τα `bookings` του Ημερολογίου.
- Έγκριση δράσης από Πρόεδρο μέσα από το Hub.
- Email 1: ανακοίνωση δράσης με κουμπί «Δήλωση συμμετοχής» προς την υπάρχουσα φόρμα του Ημερολογίου.
- Email 2: Zoom, μόνο στους πραγματικά εγγεγραμμένους συμμετέχοντες.
- Μηνιαίες συναντήσεις μελών: ενημέρωση μόνο στα Μέλη και αυτόματο task για Zoom μία ημέρα πριν.

## Βασική ροή δράσης

Θεραπευτής → Ημερολόγιο → Πρόεδρος εγκρίνει → Γραμματεία στέλνει ανακοίνωση → συμμετοχές στο υπάρχον event form → για πληρωμένη δράση αποστέλλεται κουμπί «Έκανα την κατάθεση» → δήλωση εμφανίζεται στον Ταμία → Ταμίας επιβεβαιώνει → μία ημέρα πριν η Γραμματεία στέλνει Zoom μόνο στους εγγεγραμμένους.

## Local development

```sh
npm install
npm run dev
```

## Vercel

Κάνε push το repository στο GitHub και import στο Vercel. Πρόσθεσε τις μεταβλητές του `.env.example` στο Vercel Project → Settings → Environment Variables.

## Σημείωση ασφάλειας pilot

Το Hub εξακολουθεί να χρησιμοποιεί Anonymous Firebase Auth ώστε τα 5 μέλη να έχουν απλή κοινή πρόσβαση. Μην κοινοποιείς δημόσια το URL του Hub. Η δημόσια φόρμα συμμετοχής και η δημόσια δήλωση κατάθεσης παραμένουν στην εφαρμογή Ημερολογίου, ώστε να μην ανοίγουμε το οικονομικό Firestore του Hub σε εξωτερικούς συμμετέχοντες.
